# Resume

This is the frontend module for `juanez.io`, built to showcase my resume, portfolio, and personal brand.

It runs as a standalone app but is designed to be integrated into the full platform via `platform-gateway` and `platform-infra`.

Vite is used for local development, but the general idea is to deploy and serve the build via Nginx.

---

## 🛠️ Stack

- ⚛️ React
- ⚡ Vite
- 💨 Tailwind CSS
- 🐳 Dockerized for deployment
